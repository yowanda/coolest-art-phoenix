# Coolest Art — Phoenix Rising

Entry for make.fun `coolest-art-01` ("Make the coolest art", $250).

A phoenix rising through fire and embers — a single dramatic image built
for a pairwise AI judge: high contrast, a clear central subject, and
emotion that reads at a glance.

## How it works

`main.py` (Python 3.13, stdlib only) copies `entry.png` to
`/output/entry.png`. Fully deterministic: every run writes the exact same
bytes, no network access.

## Files

- `main.py` — the entry program
- `entry.png` — the artwork (512x768 PNG)
- `LICENSE` — MIT
